# Lane GEO2: continent tiers, neighbours rework, answer-leak audit

Owner of `js/geo/` (incl. `js/geo/formats/`). Small fixes elsewhere are logged under "Edits outside js/geo".

## 1. Continent: clue tiers (`js/geo/formats/continent.js`)
- New option **Ask about**: Mix (default) / Countries / Cities (kids default Countries). Cities come from `data/geo/cities.json`:
  only UN members that sit on one continent (no `cs`), inside the country's main-part box (no Honolulu, Canaries, Ceuta),
  Indonesia west of 129°E, names that are unique across continents plus a hand list of names shared with famous places
  elsewhere (Tripoli, Córdoba, Santiago, Perth, London…), no names containing the country ("Kuwait City"), and a few
  Natural Earth population oddities dropped (Amaravati, Haora…). 341 cities, each with a fame 1–3.
- **Tiers** (`q.data.tier`): easy / kids = **dot** (country pulses, city gets a dot); medium = **line**: one faint dashed
  parallel or meridian through the place, sub-line "X is somewhere on the dotted line"; hard = **name only** (blank, faded
  map). Mixed difficulty picks the tier by fame (famous → name only, obscure → dot). "Show map: No" = name only, no map.
- **Line choice**: `chooseLine()` takes whichever of the parallel/meridian crosses more continents (coin toss on ties), so it
  crosses ≥ 2 whenever either does. Crossings come from `js/geo/bands.js` (generated by `node tools/geo2_bands.mjs` from
  world.json): per 0.25° row, a bitmask of the continents an exact line at the row centre crosses; the line is drawn at
  that row centre (≤ 0.125° from the place), so the data is exact for the drawn line. Transcontinental countries are left
  out of the bands, so counts err low. In practice parallels always win or tie (164 lat wins, 0 meridian wins, 21 ties
  over country label points), so meridians appear only on ties.
- **Reveal**: the map switches to continent colours and shows the true place as a green dot with its name (countries too,
  so tiny ones like the Seychelles are visible), the line stays.
- Map: `map.addPath([[lon,lat]…], {cls})` (polyline as given; `addLine` is great-circle) and `.gm-line.clue`, `.gm.faded` CSS.

## 2. Neighbours rework (`js/geo/formats/neighbours.js`)
Option **Questions**: Mix (default: ~65% pick, 35% how-many) / Pick the neighbours / How many? / Tap on the map (the old
picker, adults only, still uses "Wrong taps allowed").
- **Pick** (multi-select, 6 options, no map until answered): easy "Which of these borders X?" (1 correct, tap = answer);
  medium "Which 2|3 of these border X?" ; hard "Pick all N countries that border X" (every real neighbour is in the list,
  2–4 of them). Hint line "Exactly N of these 6 do · k picked", Check button reads "Pick k more" until exactly N are
  picked (can't pick more than N). Partial credit `points = 100·hits/N`. Reveal: map of the region with the country
  (yellow), every real neighbour (green, labelled), the decoys (red, labelled), disputed neighbours soft; options marked
  ok / missed (dashed green) / wrong / dim.
- **Decoys**: same continent, not a neighbour either way, area ≥ 500 km², not disputed. Easy: distance rank 4–18 (clearly
  off); medium: the 12 nearest; hard: neighbours-of-neighbours first. Small continents (Brazil borders nearly all of
  South America) top up with the nearest others.
- **How many?**: 4 consecutive-ish numbers around the true count (all ≥ 1); explain lists them and says "Counting land
  borders with independent countries." Only countries with no disputed or overseas border (so never France, Spain,
  Brazil, Suriname, Morocco, Serbia, Israel…). Easy ≤ 5 neighbours, medium ≤ 8.
- **Fairness rules**: islands (0 neighbours) are never asked. Disputed places (Palestine, Kosovo, Taiwan, W. Sahara) are
  never asked, offered or counted; explains add "It also borders Kosovo, whose status is disputed." Overseas borders
  (France–Brazil/Suriname via French Guiana, Spain–Morocco via Ceuta/Melilla) are never easy/medium options; hard "all"
  includes them (they are true) with the explain note, and hard skips countries with a disputed neighbour.
- **Kids**: "Tap a country that borders X", one tap answers, only countries whose neighbours are all big enough:
  `tapSizes()` mirrors map.js's fly-to fit in a 340×300 box (smaller than the kids map at all three viewports) and needs
  each neighbour ≥ 22 px equal-area side and ≥ 14 px on its thin side; no disputed/overseas neighbours; `d ≤ 2`. 61
  countries (Kenya, Portugal, USA, Bolivia, Nigeria…; never Italy, France, Spain, Switzerland, South Africa).
- The reveal/map view ignores French Guiana for European questions (France's `mb` reaches it) and clips other countries
  to 20° around the subject.

## Geo formats + kids
The shell passes `kids` as a top-level `generate()` argument, not `opts.kids`, so the geo formats never generated their
kids variants in the real app (only in dev.html). All seven now read `opts.kids || kids`.

## 3. Answer-leak audit
`node tools/geo2_leak_test.mjs [formats] [--vp=WxH] [--n=3] [--shots DIR] [--break]` plays every registered format in the
real app (`?test`, quick structure), normal + kids for kids-tagged formats, 2–5 packs each (mammals, flags, countries,
movie-moments, paintings, landmarks, dogs, quotes, music…), and before answering checks: picture-option names not in
visible text, alt/title/aria-label, broken-image alt text, or the read-aloud speech; the answer not in alt/title/aria-label
or svg titles, and not on screen for formats whose answer shouldn't be visible; no credits ⓘ button and no reveal card yet.
Plus Aaron's exact "Which of these is a capybara?" question found by seed in mc, odd and ladder (normal + kids) and Duel
(picture question, then player 1 answers wrong).

Found and fixed:
1. **Duel lockout** (`js/structures/duel.js`): a wrong answer called `grid.mark(-1, i)`, which adds `.revealed` and shows
   every picture's name on the locked player's half while the other player is still choosing. Now only the picked
   button gets `.wrong`.
2. **Kids music artwork** (`js/audio/listen.js`): kids forced album art `on` from the start; covers often print the title
   (soundtracks show the film). Kids now get `blur`, which sharpens as the clip plays.
3. **Read-aloud** (`js/ui/speech.js`): options were read out unless `data.layout === 'images'`; any option with a picture
   now also stops it (defensive: every current picture format sets the layout).
Already fixed by the manager: kids picture labels (`.play.kids .choices.images` labels only when locked/revealed).

Checked clean: mc/odd/ladder/lookalike/reveal/type/fake/quote/silhouette/hilo/match/sort/order/number/connect/blitz60/
chain/tf/listen/movie-moments and all 7 map formats, normal + kids, 384×854, 854×384, 1280×800. Credits ⓘ appears only
on the reveal card (so Commons titles like "Flag_of_Belgium.svg" are never shown early). Picture `alt` is "Option N"
(choice grids), "Picture N" (match), "" elsewhere; the flag in map rounds is alt "Flag". The capybara question has no
visible names in mc/odd (normal + kids) and Duel; ladder never builds a capybara picture question (no clues), its kids
picture rounds were checked instead.
Not changed (by design): hilo/sort/chain show names with their pictures because the name is not the question.
Residual: image URLs (Commons file names) are in the DOM, so a long-press "open image" or dev tools would show them.
