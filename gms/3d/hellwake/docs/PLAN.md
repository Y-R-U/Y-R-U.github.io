## Shared contract (ES modules)
### content.mjs
Export CHAPTERS (six objects): {id:0..5,title,subtitle,location,color(hex string),duration(seconds, first 100 then 140-210),objective:{type:'seal'|'rescue'|'beacon',label,count},boss:{name,type},intro:[{speaker,text}],outro:[{speaker,text}],unlock:string}. Export WEAPONS: array {id,name,icon (string glyph),color,description,evolution:{name,requires:string,description},unlockChapter:number}. Weapon ids: pistol, orbit, lightning, flame, shotgun, frost, drone, scythe. Passive ids: might, haste, vitality, magnet, reach, fortune. Export PASSIVES array {id,name,icon,description}; SURVIVORS array {id,name,title,description,weapon,unlockChapter,color}; first id 'mara', weapon pistol. Export RELICS array {id,name,description,max,cost,perLevel}; ids vitality,might,haste,magnet. Export getDraft(run, rng=Math.random): three upgrade objects {id,kind:'weapon'|'passive'|'evolution'|'heal',name,icon,description,color?}. run.weapons and run.passives are maps id->level; run.chapter numeric; run.arsenalChapter optionally specifies the highest permanently unlocked chapter for replay weapon availability. Upgrades max weapon 5, passive 3; evolution requires weapon5+matching passive3 and is tracked in run.evolved map.
### progression.mjs
Export loadSave(storage=localStorage), persistSave(save,storage=localStorage), newSave(), buyRelic(save,id) -> boolean (mutates), recordRun(save,result) -> {newChapter:boolean,unlocks:string[]}; unlockedChapter is highest playable index 0..5. Save shape {version:1,embers:0,unlockedChapter:0,completed:[],relics:{},selectedSurvivor:'mara',settings:{sound:true,quality:'auto',reducedMotion:false},stats:{runs:0,kills:0,bestEndless:0},endingSeen:false}. Result {victory,chapter,kills,seconds,embers,endless}. recordRun applies awards once per call; root calls only once at run end.
### engine.mjs
Export class GameEngine. Constructor({chapter=0,unlockedChapter=chapter,survivor='mara',relics={},endless=false,seed=1,onEvent=()=>{}}). .state public serializable object. .update(dt,input={x:0,y:0}) seconds, .chooseUpgrade(index), .pulse() -> boolean, .setPaused(bool). Input normalized by engine. .state {phase:'playing'|'upgrade'|'won'|'lost',paused,time,chapter,endless,player:{x,y,hp,maxHp,angle,invincible},enemies:[],projectiles:[],gems:[],effects:[],zones:[],objectives:[],weapons:{pistol:1},passives:{},evolved:{},level,xp,xpNext,kills,embers,pulseCharge:0..1,draft:[],objectiveDone,objectiveTotal,boss:null|enemy,result:null|{...}}. All world coords x,y ground plane, approximate arena +-24. Units {id,x,y,angle,hp,maxHp,radius,type,hit?}, enemies types walker,runner,brute,spitter,boss. Projectiles {id,x,y,angle,radius,type,color?}; gems {id,x,y,value}; effects {id,x,y,type,radius,life,maxLife,color?}; zones {id,x,y,radius,life,maxLife,type,color?}; objectives {id,x,y,radius,progress:0..1,done,type}. Boss is also in enemies. Radius player ~0.5; world move speed ~5.5. Renderer never mutates state. Engine cleans expired effects. Objectives charge by proximity; allow convenient encounter locations. Boss at duration; win needs objectives plus boss kill, no deadline death. events callback {type:'shot'|'hit'|'kill'|'level'|'boss'|'objective'|'pulse'|'win'|'lose'|'evolve'|'toast',text?}. Pulse charged by kills and time, start charged for accessible teaching. Engine uses content getDraft; no DOM. First chapter gentle but pacing builds.
### renderer.mjs
Export class WorldRenderer constructor(canvas,{quality='auto',reducedMotion=false}={}); .render(state,dt); .resize(); .setQuality(value); .setReducedMotion(bool); .dispose(); .stats() -> {drawCalls,triangles,...}. Engine x,y maps Three x,z. Camera follows player, portrait ground visible width ~22 units, lit player centered ~52% vertically, headroom for HUD. Render can accept null state for attractive title diorama. Include visually distinct zombies, demon boss, player, projectiles, gems, objectives and radius rings, weapon orbit visuals. Budget hordes up to 200, pooled/instanced geometry, no per-unit lights or shadows. Local Three import ../.. /lib is actually ../../lib/three/0.160.0/three.module.js relative to this directory. Favor crisp teal/spectral mint against ink/navy and hot coral demonic threat. Street, ruined buildings and glowing portal, fog, fake glow, procedural details. No external images required.
